## NextAuth 사용 계기

로그인 기능 구현 중 **OAuth**가 필요했고, 직접 인증 흐름을 구축하는 대신  
Next.js에 최적화된 인증 라이브러리인 **NextAuth**로 빠르게 구성하기 위해 선택했습니다.

---

## NextAuth란?

Next.js에서 인증을 쉽게 구성할 수 있도록 도와주는 라이브러리입니다.

- OAuth(GitHub, Google 등)와 Credentials 인증을 지원
- 세션 관리(JWT/DB), 보안 쿠키 처리 자동화
- 서버/클라이언트에서 인증 상태를 쉽게 조회 가능
- 다양한 DB 어댑터(Prisma 등)와 연동 가능

---

## NextAuth v5 특징

- App Router 우선 지원(기존 Pages Router도 호환)
- 설정 구조 간소화(`auth.ts` 중심 구성)
- Preview 환경/Edge Runtime 관련 지원 개선
- 계정 연결 콜백 등 인증 흐름 확장성 강화

## 기본 구성 (App Router)

### 1) 핵심 파일 구조

- `src/auth.ts`: NextAuth 설정을 모으는 진입점
- `src/app/api/auth/[...nextauth]/route.ts`: 라우트 핸들러 연결

### 2) NextAuth 기본 구조

```ts
// src/auth.ts
import NextAuth from "next-auth";
import GitHub from "next-auth/providers/github";

export const { handlers, signIn, signOut, auth } = NextAuth({
  providers: [
    GitHub({
      clientId: process.env.GITHUB_ID!,
      clientSecret: process.env.GITHUB_SECRET!,
    }),
  ],
  session: { strategy: "jwt" },
  callbacks: {
    async jwt({ token }) {
      return token;
    },
    async session({ session, token }) {
      session.user = { ...session.user, id: token.sub };
      return session;
    },
  },
});
```

#### NextAuth() 반환 함수

- `handlers`: `/api/auth` 요청을 처리하는 핸들러
- `signIn`: 서버에서 로그인 트리거(redirect 포함)
- `signOut`: 서버에서 로그아웃 트리거
- `auth`: 서버 컴포넌트/라우트에서 세션 조회

#### NextAuth 옵션

- `providers`: OAuth/자격 증명 공급자 목록
- `session`: 세션 전략(`jwt` 또는 `database`)
- `pages`: 커스텀 로그인/에러 페이지 경로 지정
- `callbacks`: 인증 흐름을 커스터마이징
  - `callbacks.signIn`: 로그인 허용/차단
  - `callbacks.redirect`: 로그인 후 이동 경로 제어
  - `callbacks.jwt`: JWT 토큰 커스터마이징
  - `callbacks.session`: 세션 객체 커스터마이징

### 3) 라우트 핸들러 연결

```ts
// src/app/api/auth/[...nextauth]/route.ts
export { GET, POST } from "@/auth";
```

## 클라이언트 로그인/로그아웃 예시

```tsx
"use client";

import { signIn, signOut } from "next-auth/react";

export default function AuthButtons() {
  return (
    <div>
      <button onClick={() => signIn("github")}>로그인</button>
      <button onClick={() => signOut()}>로그아웃</button>
    </div>
  );
}
```

## 서버 컴포넌트에서 세션 확인

```tsx
// app/(pages)/profile/page.tsx
import { auth } from "@/auth";

export default async function ProfilePage() {
  const session = await auth();

  if (!session) return <p>로그인이 필요합니다.</p>;
  return <p>{session.user?.email}</p>;
}
```

---

## 인증 흐름 요약

1. 사용자가 로그인 시도
2. `signIn` → provider 인증
3. `jwt` 콜백에서 토큰 구성
4. `session` 콜백으로 클라이언트에 세션 전달

---

## 정리

NextAuth는 OAuth와 세션 관리의 복잡성을 줄여주고,  
App Router 환경에서도 **인증 흐름을 간결하게 유지**할 수 있게 해줍니다.
